# FAQ

**The page says it's still building.**
The first build after a start reads all game data and takes a little while.
The page switches over by itself.

**An item I own shows as missing (or the other way round).**
Frameplan reads AlecaFrame's copy of your inventory. Open AlecaFrame once so it
syncs, then wait for the page to rebuild (or Settings → *Refresh the page now*).

**Why does an item not show where it drops?**
Some things come from places no drop table names (a quest, an event, a vendor
that isn't in the data). The item's details then say what the wiki says.

**Does Frameplan count Platinum as a way to get things?**
No. Frameplan plans for free-to-play: Platinum is never a source.

**Windows warns about an unknown publisher.**
The setup isn't code-signed (that costs money each year). Choose “More info” →
“Run anyway”. Updates are signed with Frameplan's own key and checked before
they are installed.

**Can I open the page on my phone?**
Yes: tray menu → *Open on phone (QR code)*, or Settings → *Phone access* on the
PC. Your phone has to be in the same home network.

**Where are my data?**
`%LOCALAPPDATA%\Frameplan`. Uninstalling keeps them; delete the folder to remove
them. (Earlier versions, called “Warframe Farmplan”, used
`%LOCALAPPDATA%\WarframeFarmplan`; Frameplan moves it on its first start.)

**How do I report a bug or wish for something?**
**Feedback** at the bottom of the navigation. Sign in with GitHub once (a free
account); each report becomes a public issue. To add a screenshot, open the
issue after sending, press Win+Shift+S, then Ctrl+V into a comment.

**How do I know an update worked?**
After an update Windows shows “Frameplan was updated to …” once. The version is
in Settings → The program (“this is …”), in the tray menu → Updates, and when
you point at the tray icon.

**Is Frameplan made by Digital Extremes?**
No. It is a free fan tool and not affiliated with Digital Extremes.
