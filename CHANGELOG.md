# Changelog

The newest version first. Each release's notes are written by `tools.release`.

## 2026.11.14.460 (2026-11-14)

- Feedback from inside the app: the new Feedback button sends a bug, wish or idea as an issue on GitHub (sign in with GitHub once, in Settings or the Feedback window).
- The navigation stays in place while you scroll, with Feedback and Settings always at the bottom; Inventory and Progression fold away with a click (remembered).
- A compact profile card with your in-game name (from AlecaFrame): click it (or point at it) for the details.
- After an update, Windows says once which version you have now; the tray icon shows the version when you point at it.
- Locked pages say more precisely what to do first (Incarnon: the quests that lead there; Arcanes: every island they come from).
- Smaller fixes for updates and phone access.

## 2026.11.14.447 (2026-11-14)

First release as Frameplan (formerly Warframe Farmplan): updates from inside the app, settings in the page.
